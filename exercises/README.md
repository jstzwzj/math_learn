# 做题记录 / 错题本

每个知识点做 5–10 道课后基本题（策略见《学习方法.md》「做题策略」一节）。错题记三样东西：**原题、错在哪、正确思路一句话**。每周日重做本周错题，做对了就勾掉。

按周分节记录，复制下面的模板填写：

## 第 NN 周 · 知识点（例：极限的四则运算）

### 题目 1
- **原题**：（抄题或简述，例：求 `lim_{x→0} sin(3x)/x`）
- **错在哪**：（例：直接把 sin(3x) 当 sin(x)，错得 1）
- **正确思路一句话**：（例：凑出 `3 · sin(3x)/(3x)`，套第一个重要极限，得 3）
- **重做记录**：第 1 次重做 ✅（填写日期）

> 卡住超过 15 分钟就看答案，但看完必须**合上答案自己重写一遍**，再记进这里。
