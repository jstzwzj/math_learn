# 高等数学自学计划（程序员版）

> 目标：用 6 个月左右学完高等数学核心内容（同济版上册为主，下册选学），建立扎实的微积分直觉和计算能力。

## 为什么程序员学高数不吃亏

- **机器学习 / AI**：梯度下降、反向传播、损失函数，全是导数和偏导数
- **性能优化**：复杂度分析的本质是函数增长率比较（极限思想）
- **图形 / 游戏**：渲染、物理引擎靠向量和微积分
- **日常底气**：看论文不再卡在公式那一行

程序员的最大优势：**可以用代码数值验证数学结论**，这在传统课堂里是做不到的。

## 学习路线（四个阶段）

### 阶段一：函数与极限（第 1–4 周）

| 周 | 内容 |
|---|---|
| 1 | 函数复习（定义域、复合、反函数）、初等函数 |
| 2 | 数列极限、函数极限的直觉与定义 |
| 3 | 无穷小/无穷大、极限运算法则、两个重要极限 |
| 4 | 连续性与间断点、闭区间上连续函数的性质 |

**本阶段目标**：看到 `lim_{x→0} sin(x)/x = 1` 不再害怕，能解释"极限"到底在说什么。

### 阶段二：一元微分学（第 5–10 周）

| 周 | 内容 |
|---|---|
| 5 | 导数定义、几何意义、基本求导公式 |
| 6 | 求导法则（四则、复合链式法则、反函数） |
| 7 | 高阶导数、隐函数求导、参数方程求导、微分 |
| 8 | 中值定理（罗尔、拉格朗日）、洛必达法则 |
| 9 | 泰勒公式（重点！理解"用多项式逼近函数"） |
| 10 | 单调性、极值、凹凸性、最优化应用 |

**本阶段目标**：熟练求任何初等函数的导数；理解泰勒展开（这是后续理解很多近似算法的钥匙）。

### 阶段三：一元积分学（第 11–16 周）

| 周 | 内容 |
|---|---|
| 11 | 不定积分概念、基本积分表 |
| 12 | 第一类换元法（凑微分） |
| 13 | 第二类换元法、分部积分法 |
| 14 | 定积分定义（黎曼和）、性质 |
| 15 | 微积分基本定理（牛顿–莱布尼茨公式） |
| 16 | 定积分应用（面积、体积、弧长）、反常积分 |

**本阶段目标**：理解"积分是累加"，能算常见积分，明白微积分基本定理为什么是"整个微积分的核心"。

### 阶段四：进阶主题（第 17–24 周，选学，按需深入）

- 微分方程入门（一阶线性、可分离变量）
- 无穷级数（收敛判别、幂级数展开）
- 多元函数微分（偏导数、梯度——机器学习刚需）
- 重积分（二重积分为主）

## 每周节奏建议（工作日每天 1 小时 + 周末 2 小时）

- **周一~周五**：看视频或读书 40 分钟 + 动手做题 20 分钟
- **每个知识点**：至少做 5–10 道课后题（数学是练出来的，不是看出来的）
- **周日**：整理本周笔记，用自己的话写一篇周总结（费曼学习法）

## 目录结构

```
math_learn/
├── README.md            # 本文件：路线图
├── 学习方法.md           # 怎么学最有效率
├── notes/               # 你的学习笔记（按章节建文件）
│   └── 第01讲-极限的直觉.md   # 第一课，今天就可以开始
├── exercises/           # 做题记录 / 错题本
└── tools/               # 用代码验证数学的脚本
    ├── verify_limit.py       # 文字版：数值验证极限和导数
    ├── visualize_limit.py    # 图形版：四张图看懂极限（输出 limit_plots.png）
    └── animate_calculus.py   # 动画版：割线变切线/黎曼和/泰勒逼近（输出 3 个 GIF）
```

## 使用方法

1. 先读 `学习方法.md`（5 分钟）
2. 打开 `notes/第01讲-极限的直觉.md` 开始第一课
3. 学完第一课后跑一下 `python3 tools/verify_limit.py` 和 `python3 tools/visualize_limit.py`，一个看数字逼近，一个看图形化直觉
4. 之后每周在 `notes/` 里新建一个文件写笔记，在 `exercises/` 里记录错题

## 在 Windows / Linux 上运行

工程本身跨平台，脚本会自动选择当前系统的中文字体。依赖只有 matplotlib 和 pillow：

```bash
# Windows（PowerShell 或 CMD，需已安装 Python 3.8+，勾选过 "Add to PATH"）
pip install matplotlib pillow
python tools\verify_limit.py
python tools\visualize_limit.py
python tools\animate_calculus.py

# macOS / Linux
pip3 install --user matplotlib pillow
python3 tools/verify_limit.py
python3 tools/visualize_limit.py
python3 tools/animate_calculus.py
```

Windows 下首次运行若弹出"防火墙允许"提示，允许即可（本地绘图不需要联网）。GIF/PNG 输出都在 `tools/` 目录下。
